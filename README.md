## 🤝 Contributing

We welcome contributions! Please see our [CONTRIBUTING.md](CONTRIBUTING.md) for guidelines.

### How to Add Your Portfolio

1. Fork the repository
2. Add your portfolio in the correct category
3. Follow the format: `| [site.com](https://site.com/) | Your Name | Stack | Features | [🔓](https://github.com/...) |`
4. Submit a Pull Request

### What We Accept

- ✅ Developer portfolios with good design
- ✅ Open source portfolios (preferred)
- ✅ Various tech stacks and styles
- ✅ Unique and creative approaches

### What We Don't Accept

- ❌ Broken links
- ❌ Low-quality or template-only sites
- ❌ Non-portfolio websites
- ❌ Duplicate entries
