# Security policy

This repository is a curated list of portfolio examples. It has no runtime code.

For a problem with this repository itself (malicious link, unsafe embedded content, or a broken security claim), open a private advisory:

https://github.com/KodYazicam/awesome-developer-portfolios/security/advisories/new

For a vulnerability in a listed project, contact that project's maintainers. Do not open a public issue for a vulnerability.
